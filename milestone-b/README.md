# Milestone B Workspace

This folder contains practical templates to complete Milestone B end-to-end.

## Goal

Produce a complete Milestone B submission package with:

1. Needfinding summary and requirements
2. Heuristic evaluation findings
3. Interface redesign evidence
4. Redesign justification
5. Evaluation plan
6. Evaluation execution summary (if required in your milestone scope)

## Files in this folder

- `checklist.md`
- `report-template.md`
- `heuristic-evaluation-template.md`
- `evaluation-plan-template.md`
- `progress_tracker.py`

## Progress tracker (Python)

Quick progress summary:

```bash
python3 milestone-b/progress_tracker.py
```

JSON output:

```bash
python3 milestone-b/progress_tracker.py --json
```

Use a custom checklist path:

```bash
python3 milestone-b/progress_tracker.py path/to/checklist.md
```

## 7-day finish plan

### Day 1: Scope and setup

- Pick one interface and define user/task scope.
- Create a project working copy from `report-template.md`.
- Set realistic deadlines in `checklist.md`.

### Day 2: Needfinding plan and execution

- Define 1 interactive and 1 passive needfinding method.
- Collect notes and extract user needs.
- Convert notes into concrete requirements.

### Day 3: Heuristic evaluation

- Evaluate current interface with at least 5 principles.
- Log positives and issues in `heuristic-evaluation-template.md`.
- Prioritize top issues by severity and impact.

### Day 4: Redesign

- Create medium/high-fidelity redesign artifacts.
- Cover key user flows, not just single screens.
- Save visuals for insertion into your report.

### Day 5: Justification

- Map each redesign decision to prior findings.
- Explain tradeoffs and preserved strengths.
- Ensure principle vocabulary is used consistently.

### Day 6: Evaluation plan and execution prep

- Complete `evaluation-plan-template.md`.
- If milestone scope includes execution, run the plan and capture outcomes.

### Day 7: Final polish

- Tighten writing and structure.
- Verify every section has evidence, not just claims.
- Add citations and export submission format.

## Completion standard

You are done when every item in `checklist.md` is checked and each section in `report-template.md` has project-specific content, figures, and traceable evidence.
