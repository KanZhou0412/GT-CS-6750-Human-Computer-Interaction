# Milestone B Checklist

Use this as a working checklist. Replace dates and owners as needed.

## Project setup

- [ ] Confirm interface choice and access method
- [ ] Define target user groups
- [ ] Define top tasks/workflows in scope
- [ ] Set milestone deadline: `YYYY-MM-DD`

## Needfinding

- [ ] Select interactive method (survey/interview/observation)
- [ ] Select passive method (reviews/forums/data scan)
- [ ] Document sampling and recruitment approach
- [ ] Collect raw notes/data
- [ ] Build data inventory
- [ ] Derive prioritized requirements

## Heuristic evaluation

- [ ] Select principles to apply (at least 5)
- [ ] Identify strengths of current interface
- [ ] Identify weaknesses with evidence
- [ ] Assign severity/priority to issues
- [ ] Trace each issue to a redesign action

## Redesign

- [ ] Produce medium/high-fidelity artifact(s)
- [ ] Cover end-to-end task flow(s)
- [ ] Add labels/annotations where needed
- [ ] Ensure redesign addresses top issues
- [ ] Preserve positive elements from original interface

## Justification

- [ ] Map each redesign element to prior findings
- [ ] Explain tradeoffs and alternatives considered
- [ ] Use explicit HCI principle vocabulary
- [ ] Confirm claims are backed by evidence

## Evaluation plan

- [ ] Choose evaluation type (qualitative or empirical)
- [ ] Define participants and recruitment
- [ ] Define procedure and materials
- [ ] Define measures/metrics
- [ ] Define analysis approach
- [ ] Document ethics/bias controls

## Evaluation execution (if required)

- [ ] Run planned sessions/study
- [ ] Summarize findings/results
- [ ] Identify actionable design changes
- [ ] Record limitations and next iteration

## Final packaging

- [ ] Complete all report sections
- [ ] Insert figures/tables with captions
- [ ] Add references and in-text citations
- [ ] Proofread for clarity and consistency
- [ ] Export final deliverable format
