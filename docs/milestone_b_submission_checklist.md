# Milestone B Submission Checklist (CS7637 ARC-AGI)

Use this checklist to avoid losing points from missing steps.

## A) Performance submission (Gradescope)

- [ ] Run local checks on Set B Training problems before submitting.
- [ ] Confirm your agent still runs with only supported project files.
- [ ] Submit to the **Milestone B** Gradescope assignment.
- [ ] Verify the score report includes both:
  - [ ] Training B score (out of 16)
  - [ ] Test B score (out of 16)
- [ ] Confirm your selected submission is the one that should be graded.
- [ ] Target for full performance credit:
  - [ ] >= 6/16 Training B
  - [ ] >= 6/16 Test B

## B) Journal submission (Canvas)

- [ ] Start from the official JDF template.
- [ ] Answer all required Milestone B prompts:
  - [ ] Agent function/design
  - [ ] Current performance
  - [ ] Where it succeeds
  - [ ] Where it struggles and why
  - [ ] Efficiency/runtime
  - [ ] Improvement plan
  - [ ] Generalization expectations for Set C
  - [ ] Feedback requested from classmates
- [ ] Include concrete evidence (scores, examples, runtime metrics).
- [ ] Export to PDF and quickly review formatting and readability.
- [ ] Upload the final PDF to the Milestone B Canvas assignment.

## C) Optional but recommended

- [ ] Submit to peer review assignment for participation credit.
- [ ] Save your final PDF and a source copy (doc/md) in your project folder.
- [ ] Record your final Training B/Test B numbers for future milestones.
